## Featured Project: Chargeback Loss Mitigation Model
Developed a predictive model to transition a reactive, manual dispute process into a data-driven automated workflow.

* **Objective:** Reduce revenue leakage by identifying high-probability "winnable" disputes.
* **Technical Stack:** Python (`Scikit-Learn`, `Pandas`), SQL, and API integration.
* **The Problem:** Inefficient manual review of disputes led to missed deadlines and unnecessary revenue loss.
* **The Solution:** * Built a **Binary Classification Model** in Python to score disputes based on historical win rates and customer attributes.
    * Automated evidence collection (tracking numbers and IP logs) via Python scripts to ensure robust submissions.
    * Utilized **SQL** to perform correlation analysis and identify key "win drivers".
* **Impact:** * Reduced net chargeback losses by **15%**.
    * Significantly increased dispute recovery rates.
    * Optimized team productivity by flagging low-probability disputes for auto-concession.
